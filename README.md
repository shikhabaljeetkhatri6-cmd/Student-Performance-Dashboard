📊 Student Performance Dashboard

📌 Project Overview

The Student Performance Dashboard is a Python-based data analysis project developed using Jupyter Notebook. It focuses on analyzing student academic performance through data visualization and exploratory data analysis (EDA).

The dashboard helps understand students’ marks, subject-wise performance, average scores, and overall academic results using different charts and graphs.

🎯 Objectives

* Analyze student academic performance.
* Calculate total marks and percentages.
* Compare subject-wise performance.
* Identify high-performing and low-performing students.
* Represent data through interactive and attractive visualizations.
* Make data easier to understand through graphical representation.

🚀 How to Run the Project

1. Clone this repository:

git clone YOUR_GITHUB_REPOSITORY_LINK

2. Open the project folder:

cd Student-Performance-Dashboard

3. Install the required libraries:

pip install pandas matplotlib seaborn plotly ipywidgets

4. Open Jupyter Notebook:

jupyter notebook

5. Open Student_Performance_Dashboard.ipynb.
6. Run all cells to explore the analysis and visualizations.
